# Axiom-Calc
Axiom-Calc is a Python-based calculator that focuses on accuracy, simplicity, and clean code. Inspired by the mathematical concept of an axiom, this project demonstrates how fundamental programming concepts can be used to create a reliable command-line calculator.

A clean and efficient calculator built with Python, designed around the core principles of mathematical accuracy and logical simplicity. It performs essential arithmetic operations through a lightweight and user-friendly interface.
